This Space hosts the API layer, not the interactive editor UI. GenOffice's editors are built as an Electron desktop application — they talk to local file system and native-window APIs (window.aiOffice, window.desktop, …) that only exist inside the desktop app's preload bridge, so the editor UI cannot run standalone in a browser tab. This Space instead exposes a small HTTP API for programmatic use.
